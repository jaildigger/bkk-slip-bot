# Bangkok Bank slip bot

Телеграм-бот: присылаете скриншот платёжки Bangkok Bank → бот распознаёт дату, сумму,
получателя и номер транзакции → вы выбираете категорию (или создаёте новую прямо тут) →
запись сохраняется в SQLite. Картинки не сохраняются.

## Локальный запуск

1. Создать бота у [@BotFather](https://t.me/BotFather), получить токен.
2. `cp .env.example .env` и вписать `BOT_TOKEN`.
3. Установить и запустить:

```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/python bot.py
```

4. Написать боту `/start` — он покажет ваш Telegram ID. Вписать его в `ALLOWED_USERS`
   в `.env` и перезапустить: иначе пользоваться ботом сможет любой, кто его найдёт.

## Деплой на Railway

Railway собирает образ по `Dockerfile`. Настройки сервиса (сборка, `/health`, одна реплика, том `/data`)
описаны кодом в `.railway/railway.ts`; после их правки: `npm install`, `railway config plan`, `railway config apply`.
Переменные (`BOT_TOKEN` и др.) этим файлом не управляются — они задаются в дашборде.

1. [railway.com](https://railway.com) → **New Project** → **Deploy from GitHub repo** → выбрать этот репозиторий.
   Первый деплой упадёт с сообщением «На Railway нет Volume…» — так и задумано, см. шаг 3.
2. Сервис → **Variables**:
   - `BOT_TOKEN` — токен бота;
   - `ALLOWED_USERS` — ваш Telegram ID (через запятую, если несколько);
   - `PORT` = `8080`.
3. Сервис → правый клик (или ⌘K) → **Add Volume**, Mount path: `/data`.
   Без него база (`/data/payments.db`) стиралась бы при каждом деплое, поэтому бот без Volume не запускается.
4. Сервис → **Settings → Networking → Generate Domain**, порт `8080`.
   Адрес Mini App бот возьмёт из домена Railway сам — `WEBAPP_URL` и ngrok не нужны.
5. **Deploy** (или Redeploy). В логах должна появиться строка `Mini App server on http://0.0.0.0:8080, public url: https://…`.

**Перед этим остановите бота на ноутбуке.** Два бота с одним токеном мешают друг другу:
Telegram отдаёт каждое сообщение только одному из них.

Реплика должна быть ровно одна (`replicas` в `.railway/railway.ts`) — по той же причине.

## Mini App (приложение внутри Telegram)

Кнопка «Траты» слева от поля ввода (или `/app`) открывает приложение:
загрузка нескольких платёжек сразу, просмотр по месяцам и категориям, смена категории, удаление.

Telegram открывает Mini App только по публичному HTTPS-адресу, а бот работает на ноутбуке.
Поэтому `bot.py` поднимает веб-сервер на `127.0.0.1:8080`, а ngrok даёт ему публичный адрес:

```bash
ngrok http 8080
```

Адрес вида `https://….ngrok-free.app` впишите в `.env` как `WEBAPP_URL` и перезапустите бота.
Если адрес поменяется, обновите `WEBAPP_URL` и снова перезапустите бота.
Каждый запрос приложения проверяется по подписи Telegram и списку `ALLOWED_USERS`.

## Как пользоваться

- Отправить скриншот платёжки (лучше **файлом**, без сжатия — но и обычное фото обычно читается).
- Нажать категорию или «➕ Новая категория» и написать название.
- Повторно ту же платёжку бот не примет (проверка по Transaction reference).

| Команда | Что делает |
|---|---|
| `/month` / `/month 2026-10` | итоги по категориям + список платежей по дням; ◀️ ▶️ листают месяцы |
| `/months` | суммы по месяцам (последние 12) |
| `/categories` | список категорий |
| `/addcat Название` | добавить категорию |
| `/delete N` | удалить платёж #N (номер виден в `/month`) |

Стартовые категории: Электричество, Вода, Уборка, Прочая аренда, Бадминтон.
У каждого чата свой учёт — бота можно добавить в общий чат, тогда учёт будет общий.

## Устройство

- `slip_parser.py` — OCR (RapidOCR, работает локально, без внешних API) и разбор полей по меткам.
- `db.py` — SQLite: таблицы `categories` и `payments`.
- `bot.py` — aiogram 3, хендлеры и клавиатуры; запускает и веб-сервер.
- `webapp.py` — API для Mini App, проверка подписи Telegram.
- `webapp/index.html` — само приложение (одна страница, без сборки).

Ограничения: рассчитан на англоязычную платёжку Bangkok Bank (как в примере).
В именах OCR часто теряет пробелы (`JOHNSMITH`) — на учёт это не влияет.
